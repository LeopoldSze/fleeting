# CSS3

## CSS数据类型

定义的是 CSS 属性中具有代表性的值，在规范的语法格式中，使用关键字外加一对尖括号（“<” 和 ">"）表示。

CSS 语法中的符号分为字面符合、组合符号和数量符号3类：

1. **字面符合**指的是 CSS 属性值中原本就支持的合法符合，这些符号在 CSS 语法中会按照其原本的字面意义呈现，目前字面符号就两个，一个是逗号（,），另一个是斜杠（/）

   | 符号 | 名称       | 描述                                                                                                    |
   | :--- | :--------- | :------------------------------------------------------------------------------------------------------ |
   | `,`  | 并列分隔符 | 用来分隔数个并列值，或者分隔函数的参数值                                                                |
   | `/`  | 缩写分隔符 | 用来分隔一个值的多个部分，在 CSS 缩写中用于分离类型相同但属于不同 CSS 属性的值，以及用在部分 CSS 函数中 |

2. **组合符号**用来表示数个基本元素之间的组合关系，目前共有5个组合符号

   | 符号   | 名称         | 描述                                                                 |
   | :----- | :----------- | :------------------------------------------------------------------- |
   | ` `    | 并列         | 符号为普通空格字符，表示各部分必须出现，同时需要按顺序出现           |
   | `&&`   | “与”组合符   | 各部分必须出现，但可以不按顺序出现                                   |
   | `\|\|` | “或”组合符   | 各部分至少出现一个，可以不按顺序出现                                 |
   | `\|`   | “互斥”组合符 | 各部分恰好出现其中一个                                               |
   | `[]`   | 方括号       | 将各部分进行分组以绕过上面几个符号的优先规则，因此方括号的优先级最高 |

3. **数量符号**用来描述一个元素可以出现多少次，数量符号不能叠加出现，并且优先级高于组合符合，目前共有6个数量符号，大多数和正则表达式中的含义相同

   | 符号     | 名称       | 描述                                                           |
   | :------- | :--------- | :------------------------------------------------------------- |
   | ` `      | 无数量符号 | 恰好出现一次                                                   |
   | `*`      | 星号       | 可以出现任意次数                                               |
   | `+`      | 加号       | 可以出现一次或多次                                             |
   | `?`      | 问号       | 可以出现零次或者一次，也就是该元素可有可无                     |
   | `{A, B}` | 花括号     | 出现最少A次，最多B次                                           |
   | `#`      | 井号       | 可以出现一次或多次，但多次出现时必须以逗号分隔                 |
   | `!`      | 叹号       | 表示当前分组必须产生一个值，该符号多出现在组合符号方括号的前面 |

> 完整列表参考：[CSS值类型文档大全](https://www.zhangxinxu.com/wordpress/2019/11/css-value-type/)

### 全局关键字属性值

`inherit、initial、unset、revert` 都是 CSS 全局关键字属性值，也就是说所有 CSS 属性都可以使用这几个关键字作为属性值。

| 关键字    | 名称                                   | 描述                                                                                                                                 |
| --------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `inherit` | 继承                                   | 继承父元素的属性                                                                                                                     |
| `initial` | 初始值                                 | 可以把当前的 CSS 属性的计算值还原成 CSS 语法中规定的初始值，适合用在需要重置某些 CSS 样式，但又不记得初始值的场景                    |
| `unset`   | 不固定值                               | 如果当前使用的CSS属性是具有继承特性的，则等同于使用 `inherit` 关键字；否则等同于使用 `initial` 关键字，只要配合 all 属性使用才有意义 |
| `revert`  | 让当前元素的样式还原成浏览器内置的样式 |                                                                                                                                      |

### 渐进增强处理

> 语法：`@supports <supports-condition> {}`

- `@supports` 是 CSS 中的常见的@规则，可以用来检测当前浏览器是否支持某个 CSS 新特性，这是最规范、最正统的 CSS 渐进增强处理方法，尤其适合多个 CSS 属性需要同时处理的场景

- `@supports` 规则还支持使用操作符进行判断，这些操作符是 `not、and、or`，分别表示“否定、并且、或者”，实现简单的逻辑判断

  ```css
  /* 支持弹性布局 */
  @supports (display: flex) {
  }

  /* 不支持弹性布局 */
  @supports not (display: flex) {
  }

  /* 同时支持弹性布局和网格布局 */
  @supports (display: flex) and (display: grid) {
  }

  /* 支持弹性布局或者网格布局 */
  @supports (display: flex) or (display: grid) {
  }

  ``

  ```

- 还持 CSS 自定义属性的检测和选择器语法的检测

  ```css
  @supports (--var: blue) {
  }
  @supports selector(:default) {
  }

  ```

## 已有属性的增强

### 尺寸体系

<br />

#### fit-content

此关键字的样式表现就是 CSS2.1规范中的”包裹性“，这种尺寸表现和元素应用 `display: inline-block、position: absolute` 等声明类似，尺寸收缩但不会超出包含块级元素的尺寸限制。

<br />

#### min-content

此关键字的样式表现就是 CSS2.1规范中的“首选最小宽度”或“最小内容宽度”，主要由 `content-box` 决定。

<br />

#### max-content

表示最大内容宽度，作用是让元素尽可能大，保证图文内容在一行显示，哪怕最终的宽度溢出外部容器元素。

<br />

::: tip 新的尺寸体系总结

- 内在尺寸：包含 `fit-content、min-content、max-content`，尺寸表现和内容有关
- 外在尺寸：包含`stretch` 关键字，也包含 `available、fill-available` 关键字，尺寸表现和上下文有关

:::

<br />

#### 逻辑属性

::: details 逻辑属性映射

默认情况下：

- `margin-left` -> `margin-inline-start`
- `margin-top` -> `margin-block-start`
- `margin-right` -> `margin-inline-end`
- `margin-bottom` -> `margin-block-end`

设置了 `direction: rtl` ，此时 `start` 对应的就是右侧，`end` 对应的就是左侧。

设置了 `writing-mode: vertical-rl` ，此时文档流垂直且从右往左排列，则此时内联元素是从上往下排列的，inline 指的是垂直方向，block 指的是水平方向，映射变为：

- `margin-left` -> `margin-block-end`
- `margin-top` -> `margin-inline-start`
- `margin-right` -> `margin-block-start`
- `margin-bottom` -> `margin-inline-end`

:::

> 完整属性列表参考：[MDN](https://developer.mozilla.org/zh-CN/docs/Web/CSS/CSS_logical_properties_and_values)

### 边框图像

- `border-image-source` 属性值是一个 `<image>` 数据类型，和 `background-image` 属性类似
- `border-image-slice` 作用是对原始的图像进行划分，划分的方位和顺序同 margin 属性、padding 属性一样，遵循上、右、下、左的顺序
- `border-image-width` 属性和 `border-width` 属性支持的参数个数是一样的，都是1~4个，不同数量的值所对应的方位规则也是一样的

::: tip border-image-width

- `border-image-width` 属性支持使用数值作为属性值，这个数值会作为系数和 `border-width` 的宽度值相乘，最终的计算值作为边框图片宽度，也就是九宫格的宽度。因此，可以设置不同的数值来得到不同宽度的九宫格
- 百分比值是相对于元素自身的尺寸计算的，水平方向相对于宽度计算，垂直方向相对于高度计算
- 控制的是九宫格的边框宽度

:::

- `border-image-outset`：控制的是九宫格中间区域的尺寸，支持1~4个长度值，并且支持数值和长度值混合使用
- `border-image-repeat`：控制九宫格上、右、下、左四个区域图形的平铺规则，语法：`[stretch | repeat | round | space]{1, 2}`

::: tip 缩写

`border-image: <border-image-source> || <border-image-slice> [ / <border-image-width> | / <border-image-width>? / <border-image-outset>]? || <border-image-repeat>`

:::

<br />

#### 轮廓效果

| 属性           | 支持渐变 | 支持模糊   | 支持圆角      | 间隙控制 | 方向控制 |
| -------------- | -------- | ---------- | ------------- | -------- | -------- |
| `outline`      | 不支持   | 不支持     | 仅Firefox支持 | 支持     | 不支持   |
| `box-shadow`   | 不支持   | 支持       | 支持          | 不支持   | 支持     |
| `border-image` | 支持     | 可渐变模拟 | 不支持        | 支持     | 支持     |

::: tip 使用总结

- 如果需要轮廓带有渐变效果，一定是使用 `border-image` 属性
- 如果需要轮廓是纯色，且4个角为直角，优先使用 `outline` 属性，再使用 `box-shadow` 属性，最后考虑 `border-image` 属性
- 如果需要轮廓优圆角效果，则一定是使用 `box-shadow` 属性
- 如果需要轮廓和元素之间有间隙，优先使用 `outline` 属性，再使用 `border-image` 属性
- 如果需要轮廓只有一个方向，则不考虑 `outline` 属性

:::

::: danger

`border` 属性不能写在 `border-image` 属性的下方，因为 `border` 属性的缩写中包含了 `border-image` 属性相关的信息

:::

### position 属性增强

1. 可滚动元素对黏性定位的影响

   黏性定位偏移计算的元素是层级最近的那个滚动元素，因此，如果黏性定位的某个祖先元素的 overflow 属性值不是 visible ，那么窗体滚动的时候不会有黏性定位效果。

2. 黏性定位元素的父元素和自身高度计算值一样的时候没有黏性效果

3. 堆叠规则

   如果多个黏性定位元素在同一个容器中，则这几个黏性定位元素会产生重叠的情况；如果黏性定位元素分布在不同的容器中，同时这些容器在布局上是上下紧密相连的，则视觉上会表现为新的黏性定位元素挤开原来的黏性定位元素，形成依次占位的效果

4. 同时设置 `top、bottom` 属性的时候，上下两个方位的黏性效果会同时生效，水平方向也是类似

### unicode-range

> 语法：`unicode-range unicode编码/Unicode范围值`
>
> 默认值：`U+0-10FFFF`，也就是所有字符集

Unicode编码编码使用方式：

1. 在HTML中，字符输出可以使用 `&#x` 加上 Unicode 编码
2. 在JavaScript中，为了避免中文乱码需要转义，应使用 `\u` 加上Unicode编码
3. 在CSS中，如伪元素的 content 属性，直接使用 `\` 加上对应字符的Unicode编码值
4. `unicode-range` 属性则是使用 U+ 加上 Unicode编码

::: details unicode-range 常用的 Unicode 编码值

- 基本二次汉字：[0x4e00, 0x9fa5]（或十进制[19968, 40869]）
- 数字：[0x30, 0x39]（或十进制[48, 57]）
- 小写字母：[0x61, 0x7a]（或十进制[97, 122]）
- 大写字母：[0x41, 0x5a]（或十进制[65, 90]）

获取具体字符的 Unicode 编码值：`xx.codePointAt().toString(16)`

:::

### 中断与换行

字符单元默认的中断与换行规则如下：

- Space 普通空格、enter回车空格、Tab 制表空格，这3种空格无论怎样组合都会合并为单个普通空格
- 文字可以在CJK文本、普通空格和短横线连字符处换行，连续英文单词和数字不换行

**word-break**

> 语法：`word-break: normal | break-all | keep-all | break-word`
>
> `keep-all` 可以让 CJK 文本不换行排版，同时又不影响非 CJK 文本的排版行为

::: tip

- 动态文本内容使用 `word-break: break-all` 和 `word-wrap: break-word` 组合代码。如果要彻底换行，还可以使用 `line-break: anywhere`
- 静态内容排版不建议使用 `word-break、word-wrap、line-break` 属性，如果是英文单词，则使用 `&shy;` ；如果是非英文单词，则使用 `<wbr>` 标签优化排版

:::

#### HSL 颜色

- HSL 颜色由色调、饱和度、亮度这3个元素组成。色调从0~360deg大致按照红、橙、黄、绿、青、蓝、紫、红的颜色顺序分布。其中红色、绿色、蓝色对应的色调值分别为：`red = 0deg, green = 120deg, blue = 240deg`

- 饱和度和亮度的值是任意的，最终解析的数值范围均在 `0%~100%` ，数值后面的百分号一定不能少
- 和 RGB 颜色不同，控制 HSL 颜色的值可以是小数
- 色值之间可以使用空格分隔，透明度使用斜杠分隔

### background 属性增强

css 世界中，常见的图像有以下几种：

- 位图。例如 JPG 或者 PNG，这些图形总是有自己的内在尺寸（原始图像大小）和内在比例（原始图像比例）
- 矢量图。例如 SVG，这些图像不一定具有内在尺寸。如果水平尺寸和垂直尺寸都设置了，那么它就具有内在的比例；如果没有设置尺寸，或者只设置了一个方向的尺寸，它可能有比例，也可能没有比例，要视 SVG 内部代码而定
- 渐变图像。就是使用渐变语法绘制的图像，是没有内在尺寸和内在比例的
- 元素图形。例如使用 `element()` 函数把 DOM 元素作为背景图，此时的内在尺寸就是这个 DOM 元素的尺寸

::: details background-size: auto 的尺寸渲染规则

1. 如果图像水平和垂直方向同时具有内在尺寸，则按照图像原始大小进行渲染
2. 如果图像没有内在尺寸，也没有内在比例，则按照背景定位区域的大小进行渲染，等同于设置属性值为 100%。所以，渐变图像默认都是覆盖整个背景定位区域的
3. 如果图像没有内在尺寸，但具有内在比例，则渲染效果等同于设置属性值为 `contain`
4. 如果图像只有一个方向有内在尺寸，但又具有内在比例，则图像会拉伸到该内在尺寸从大小，同时宽高比符合内在比例
5. 如果图像只有一个方向有内在尺寸，而没有内在比例，则图形有内在尺寸的一侧会拉伸到该内在尺寸大小，没有设置内在尺寸的一侧会拉伸到背景定位区域大小

:::

::: details background-size属性只有一个为auto的尺寸渲染规则

1. 如果图像有内在比例，则图像会拉伸到指定的尺寸，高宽依然保持原始的比例
2. 如果图像没有内在比例，则图像会拉伸到指定的尺寸。同时，如果图像有内在尺寸，则计算尺寸就是图像的尺寸；否则，计算尺寸就是背景定位区域的尺寸

:::

::: info

`background-size` 属性值无论是数值还是百分比值，都不能是负值，其中百分比值是相对于元素的背景定位区域计算的。背景定位区域是由 `background-origin` 属性决定的，默认值是 `padding box`

:::

::: danger 注意

`background-size` 属性值是可以作为缩写直接在 `background` 属性中设置的，但是只能写在 `background-position` 属性值的后面，并且使用斜杠分隔，其他写法都是无效的

:::

#### 背景位置控制

background-position

::: info 1个值语法

如果只有一个值，无论是具体的数值、百分比值，还是关键字属性值，则另外一个值一定是 `center`

:::

::: info 2个值语法

1. 2个值都是关键字属性值，left 和 right 表示水平方向，top 和 bottom 表示垂直方向，因此 `top right` 和 `right top` 效果是一样的，不能包含对立的方位
2. 1个值是关键字属性值，另外一个值是数值或者百分比值。如果数值或百分比值是第一个值，则表示水平方向，另一个关键字属性值就是垂直方向；如果数值或百分比值是第二个值，则表示垂直方向，另外一个关键字属性值就表示水平方向。因此 `20px left` 非法，left 不是垂直方向的
3. 2个值都是数值或百分比值。第一个值表示水平方向，第二个值表示垂直方向

:::

::: info 3个值和4个值语法

数值和百分比表示偏移量，第一个值一定要是关键字属性值，用来表示偏移是从哪个方向开始的。如果是3个值，则认为缺少的偏移量是0.

:::

## 更细致的样式表现

### opacity

::: warning

- 在所有支持 CSS 过渡和动画的属性中，opactity 属性的性能是最高的，因此很多动画效果都可以使用此属性进行性能优化
- 由于 opacity 没有继承性，因此父子元素同时设置该属性时，半透明效果是相乘叠加的

:::

<br />

### border-radius

> 是 `border-top-left-radius、border-top-right-radius、border-bottom-left-radius、border-bottom-right-radius` 的缩写

::: details 不同数量属性值

1. 如果只有1个值，则表示圆角效果作用于全部四个角
2. 如有有2个值，则第一个值作用于左上角和右下角，第二个值作用于右上角和左下角
3. 如果有3个值，则第一个值作用于左上角，第二个值作用于右上角和左下角，第三个值作用于右下角
4. 如果有4个值，则4个值按照顺时针顺序方向依次作用于左上角、右上角、右下角和左下角

如果针对单个角的属性值用空格分开写，分别表示水平半径和垂直半径；如果针对4个角的属性值，用/分隔，分别表示水平半径和垂直半径。

:::

<br />

### box-shadow

> 定义：内外 + 偏移 + 模糊 + 颜色，偏移支持2~4个长度值，前两个长度值是固定的，分别表示水平偏移和垂直偏移，第三个表示模糊半径，第四个表示扩展半径

::: tip

- 内阴影和的水平和垂直方向和外阴影一致，都是左上角光源
- 生成的阴影会位于文字内容的下面，背景颜色的上面
- 对于部分替换元素是无效的，因为替换元素的内容在盒阴影之上，此时可以使用 `outline` 属性进行模拟，如：`outline: 3px solid rgba(0, 0, 0, .1); outline-offset: -3px;`
