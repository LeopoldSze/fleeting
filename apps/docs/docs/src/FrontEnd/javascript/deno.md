# Deno

> [官方资源库](https://deno.land/x)

| 特性     | Node.JS           | Deno                                                     |
| -------- | ----------------- | -------------------------------------------------------- |
| API引入  | 模块导入          | 全局                                                     |
| 模块类型 | CommonJS、ESM     | ESM，也可以是远程模块                                    |
| 安全策略 | 默认无安全限制    | 默认安全，外部代码没有模块、文件和网络权限，除非显示开启 |
| TS支持   | 需要其他模块支持  | 开箱即用                                                 |
| 包管理   | npm               | 原生ESM支持，不需要npm包                                 |
| 包分发   | npm仓库           | 去中心化                                                 |
| 入口文件 | package.json 文件 | 直接引入文件                                             |
