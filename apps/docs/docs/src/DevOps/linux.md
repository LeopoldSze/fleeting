# Linux

## 目录结构

Linux的目录结构是一个树形结构，Windows系统可以拥有多个盘符，Linux没有盘符这个概念，只有一个根目录 / ，所有文件都在它下面。

- 出现在开头的 / 表示：根目录
- 出现在后面的 / 表示：层次关系

<br />

### 路径

> 绝对路径：以根目录为起点，路径描述以 / 开头
>
> 相对路径：以当前目录为起点，路径描述无需以 / 开头

Linux系统的命令行终端，在启动的时候，默认会加载：

- 当前登录用户的HOME目录作为当前工作目录
- HOME目录：每个Linux操作用户在Linux系统的个人账号目录，路径在：`/home/用户名`

<br />

### 文件夹说明

| 文件夹   | 说明                                                                                                                                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`      | 根目录，所有目录位于此目录之下                                                                                                                                                                                                            |
| `/bin`   | 存放系统启动和运行时需要的基本命令和可执行文件（如 `ls`, `cp`, `cat`, `mkdir` 等）。这些命令对所有用户都可用                                                                                                                              |
| `/boot`  | 存放启动所需的文件，包括 Linux 内核 (`vmlinuz`)、初始内存盘 (`initrd`)，以及启动加载器的配置文件（如 `grub`）                                                                                                                             |
| `/cdrom` | 光驱相关文件                                                                                                                                                                                                                              |
| `/dev`   | 存放设备文件，用于与系统的硬件设备（如硬盘、终端、打印机等）进行交互。例如 `/dev/sda` 是第一个硬盘，`/dev/tty` 是终端设备                                                                                                                 |
| `/etc`   | 存放系统的配置文件和启动脚本。大多数系统配置文件和应用程序配置文件都位于此目录。例如：`/etc/passwd`、`/etc/network/interfaces`、`/etc/apt/sources.list` 等                                                                                |
| `/home`  | 存放用户的个人文件和配置目录。每个用户通常会有一个以其用户名命名的目录（如 `/home/username`），存放该用户的数据和配置                                                                                                                     |
| `/lib`   | 存放系统运行时所需要的共享库文件。这些库文件是程序运行所依赖的，例如 C 标准库                                                                                                                                                             |
| `/media` | 存放临时挂载的可移动设备（如 USB 闪存盘、CD/DVD 等）。在插入外部设备时，它们通常会被挂载在该目录下                                                                                                                                        |
| `/mnt`   | 用于挂载临时文件系统。通常用于系统管理员手动挂载的文件系统                                                                                                                                                                                |
| `/opt`   | 存放第三方应用程序的软件包。通常是安装的商业软件或大型程序，独立于操作系统管理的软件包                                                                                                                                                    |
| `/proc`  | 一个虚拟文件系统，提供系统和进程的内存映射信息，允许用户查看和更改系统状态（如 `/proc/cpuinfo` 提供 CPU 信息）。它不占用磁盘空间，所有内容都是实时生成的                                                                                  |
| `/root`  | 根用户（超级用户）的家目录。不同于普通用户的家目录，根用户用于系统管理工作                                                                                                                                                                |
| `/run`   | 存放系统启动时的运行时数据，例如系统和服务的 PID 文件、锁文件等。它是一个临时文件系统，在每次启动时重新创建                                                                                                                               |
| `/sbin`  | 存放系统管理程序和二进制文件，这些文件通常只供超级用户（root）使用。例如，`fdisk`, `ifconfig`, `reboot` 等                                                                                                                                |
| `/snap`  | 系统快照文件                                                                                                                                                                                                                              |
| `/srv`   | 存放提供给系统服务的数据。例如，Web 服务器的根目录可能会位于 `/srv/www`                                                                                                                                                                   |
| `/sys`   | 一个虚拟文件系统，提供关于内核、硬件、驱动程序等的信息。它允许用户查看和更改内核参数                                                                                                                                                      |
| `/tmp`   | 存放临时文件，系统和应用程序会使用该目录来存放临时产生的数据。文件可能会定期删除                                                                                                                                                          |
| `/usr`   | 存放用户的应用程序和共享的只读数据。通常包含以下子目录：<br /> `/usr/bin`：大多数用户命令<br />`/usr/lib`：程序库文件 <br />`/usr/share`：共享数据（如帮助文件、文档等）<br />`/usr/local`：用于存放本地安装的软件                        |
| `/var`   | 存放不断变化的数据文件，如日志文件、邮件队列、数据库文件等。常见子目录包括：<br />`/var/log`：日志文件<br />`/var/mail`：邮件存储<br />`/var/www`：Web 服务器的根目录<br />`/var/spool`：用于存放等待处理的任务（如打印队列、邮件队列等） |

## root

> 概述：Windows、Linux、Mac系统均采用多用户模式。Linux系统中唯一超级管理员为 `root` ，拥有最大的系统操作权限。

- 普通用户的权限，一般在其HOME目录内是不受限的
- 一旦出了HOME目录，大多数地方，普通用户仅有只读和执行权限，无修改权限

### sudo

> 概述：不建议长期使用root用户，避免带来系统损坏。可以使用 `sudo` 命令，为普通的命令授权，临时以 root 身份执行
>
> 语法：`sudo 命令`

- 在命令之前，带上 sudo，即可为这条命令临时赋予root授权
- 但是并不是所有的用户，都有权利使用sudo，我们**需要为普通用户配置sudo认证**

<br />

### 配置sudo认证

方式一：

1. 将用户添加到sudo组：`sudo usermod -aG sudo 用户名`
2. 验证：`groups 用户名`

方式二：不推荐

1. 切换到root用户，编辑 `/etc/sudoers` 文件
2. 在文件的最后添加：`用户名 ALL=(ALL) NOPASSWD: ALL`
3. 切换回普通用户，sudo 执行的命令，均以root运行

## APT软件包管理器

> 概述：APT(Advanced Packaging Tools)是Debian及其派生Linux的软件包管理器，可以自动下载、配置，安装二进制或者源代码格式的软件包。
>
> 使用：`apt [选项] 命令`

| 命令                       | 说明                                                                                                                                                                                                                        |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apt list`                 | 根据名称列出软件包                                                                                                                                                                                                          |
| `apt edit-resoures`        | 编辑软件源文件                                                                                                                                                                                                              |
| `apt search`               | 搜索软件包描述                                                                                                                                                                                                              |
| `apt show xxx`             | 显示软件包细节                                                                                                                                                                                                              |
| `apt install xxx`          | 安装软件包                                                                                                                                                                                                                  |
| `apt reinstall xxx`        | 重新安装软件包                                                                                                                                                                                                              |
| `apt remove`               | 移除软件包                                                                                                                                                                                                                  |
| `apt depends xxx`          | 显示软件包的依赖关系                                                                                                                                                                                                        |
| `apt satisfy`              | 使系统满足依赖关系字符串                                                                                                                                                                                                    |
| `apt --fix-broken install` | 修复缺失依赖                                                                                                                                                                                                                |
| **`apt update`**           | 更新可用软件包列表：<br />**不** 安装任何软件包，只是刷新本地的包信息，使得系统知道哪些包有新版本可用<br />**建议至少每周运行一次**，尤其是当需要安装或升级软件包时，应该先执行 `apt update` 以确保本地的软件包列表是最新的 |
| **`apt upgrade`**          | 通过 安装/升级 软件来更新系统<br />会根据 `apt update` 更新的包索引信息，自动下载并安装新版本的包<br />建议定期运行，通常每周或每月一次，以确保系统安装了最新的软件版本和安全更新                                           |
| `apt full-upgrade`         | 通过 卸载/安装/升级 来更新系统                                                                                                                                                                                              |
| `apt clean`                | 清除本地包缓存，删除所有下载的 `.deb` 包                                                                                                                                                                                    |
| `apt autoclean`            | 只会删除旧的和不再需要的包缓存，保留当前已安装和可用的软件包                                                                                                                                                                |
| `apt autoremove`           | 卸载所有自动安装且不再使用的软件包                                                                                                                                                                                          |

::: info 管理器对比

**`apt-get`**：

- `apt-get` 是较旧的命令行工具，属于 `APT` 工具集的一部分，专门用于处理软件包的安装、升级、删除等任务
- 它提供了更低级的命令，允许用户执行复杂的任务，例如处理系统级的包管理。
- 输出更加详细，适合于脚本自动化和调试，在安装软件包时会列出详细的过程和进度信息。

**`apt`**：

- `apt` 是在 Ubuntu 16.04 和 Debian 8 等新版本中引入的，旨在简化 `apt-get` 和其他工具（如 `apt-cache`）的功能。
- `apt` 命令提供了一个更易用的接口，将 `apt-get`、`apt-cache` 和其他工具的一些常用命令合并到一个命令中。
- 输出更加简洁，并且针对常用的命令进行了优化。例如，`apt` 会以进度条的形式展示安装过程，输出的信息更加清晰，适合日常使用。

:::

## 更换镜像源

1. 备份当前的软件源配置

   ```bash
   sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
   ```

2. 编辑 `/etc/apt/sources.list` 文件，替换为更快速的镜像源，如阿里云镜像源

   ```bash
   sudo vim /etc/apt/sources.list
   ```

3. 更新软件包列表

   ```bash
   sudo apt update
   ```

### 系统管理操作

> 概述：Ubuntu系统默认开启防火墙(服务名：`ufw`)后只开放22端口给SSH服务使用，其他端口需自行打开
>
> 服务地址：`/usr/lib/systemd/system`，该目录下每个文件都对应一个服务

| 系统服务命令                | 说明                 |
| --------------------------- | -------------------- | ------------------------- | -------------- | ------------------------------------- |
| `systemctl start            | stop                 | restart                   | status 服务名` | 设置开启、关闭、重启、查看状态 - 服务 |
| `systemctl list-unit-files` | 查看服务开机启动状态 |
| `systemctl enable           | disable 服务名`      | 开启、关闭服务 - 自动启动 |

| 关机&重启命令 | 说明                                     |
| ------------- | ---------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `halt`        | 关闭系统，当前版本Ubuntu不会断电(很少用) |
| `poweroff`    | 关闭系统并断电，等同于 `shutdown -h now` |
| `reboot`      | 重启，等同于 `shutdown -r now`           |
| `shutdown [-h | -r                                       | -c] [时间]` | 关机操作<br />-h：关机，不完全等同于halt命令<br />-r：重启<br />-c：取消关机<br />时间：`now`，立刻关机；分钟时间，等待多久后关机 |

> 概述：每一台电脑除了对外联络地址（IP地址）以外，也可以有一个名字，称之为主机名。无论是Windows或Linux系统，都可以给系统设置主机名

| 主机名命令                              | 说明                                           |
| --------------------------------------- | ---------------------------------------------- |
| `hostname`                              | 查看主机名<br />                               |
| `hostnamectl set-hostname xxx`          | 修改静态主机名、动态主机名和预设主机名         |
| `hostnamectl --static set-hostname xxx` | 仅修改静态主机名，命令提示符更新需要重启后才行 |

::: info 静态主机名 vs 动态主机名 vs 预设主机名

- **静态主机名**：是系统的永久主机名，通常在 `/etc/hostname` 文件中定义，并在系统启动时加载。它在系统重新启动时保持不变。
- **动态主机名**：是由网络配置（通常由 DHCP 或网络管理工具提供）在运行时分配的主机名。它可以随网络变化而变化。
- **预设主机名**：是系统的初始配置文件（例如 `/etc/machine-info`）中定义的主机名，它用于初始化系统的主机名。

:::

### 软链接

> 概述：在系统中创建软链接，可以将文件、文件夹链接到其他位置。类似Windows系统中的快捷方式，且删除软链接之后并不影响源文件
>
> 语法：`ln -s source dest`

- -s ：创建软链接
- source：被链接的文件或文件夹
- dest：要链接去的目的地

### 管道符

> 概述：管道符，将左边命令的结果，作为右边命令的输入
>
> 使用：`命令 | 命令`

### echo

> 作用：在命令行内输出指定内容
>
> 语法：`echo 输出的内容`

- 无需选项，只有一个参数，表示要输出的内容，复杂内容可以用“ ”包围
- 反引号``包围的 内容，会被作为命令执行，而非普通字符

<br />

### 重定向符

- `>` ：将左侧命令的结果，**覆盖**写入到符号右侧指定的文件中
- `>>`：将左侧命令的结果，**追加**写入到右侧指定的文件中

### 权限控制

权限细节共分为10个槽位：

- 第一位：- 或 d 或 l，- 表示文件，d 表示文件夹，l 表示软链接
- 第2-4位：所属用户权限，r 或 -，w 或 -，x 或 -
- 第5-7位：所属用户组权限，r 或 -，w 或 -，x 或 -
- 第8-10位：其他用户权限，r 或 -，w 或 -，x 或 -

rwx:

- r 表示读权限，针对文件可以查看文件内容，针对文件夹，可以查看文件夹内容，如 ls 命令
- w 表示写权限，针对文件表示可以修改此文件，针对文件夹，可以在文件夹内：创建、删除、改名等操作
- x 表示执行权限，针对文件表示可以将文件作为程序执行，针对文件夹，表示可以更改工作目录到此文件夹，即 cd 进入

**权限的数字序号：**

权限可用3位数字来代表，第一位数字表示用户权限，第二位表示用户组权限，第三位表示其他用户权限。

数字的细节如下：r 记为4，w 记为2，x 记为1，可以有：

- 0：无任何权限，即---
- 1：仅有x权限，即--x
- 2：仅有w权限，即-w-
- 3：有w和x权限，即-wx
- 4：仅有r权限，即r--
- 5：有r和x权限，即r-x
- 6：有r和w权限，即rw-
- 7：有全部权限，即rwx

| 命令                                             | 说明                                                                                    |
| ------------------------------------------------ | --------------------------------------------------------------------------------------- |
| `sudo chmod [-R] 权限 文件或文件夹`              | 修改文件或文件夹的权限信息<br />-R：对文件夹内的全部内容应用同样的操作                  |
| `sudo chown [-R] [用户][:][用户组] 文件或文件夹` | 修改文件、文件夹的所属用户和用户组<br />-R：同 `chmod` ，对文件夹内全部内容应用相同规则 |

如：

- `chmod u=rwx,g=rx,o=x hello.txt` ：将文件权限修改为： `rwxr-x--x`
  - u 表示user所属用户权限，g 表示group组权限，o 表示other其他用户权限
- `chmod -R u=rwx,g=rx,o=x test`：将文件夹test以及文件夹内全部内容权限设置为：`rwxr-x--x`
- `chmod 755 test` 表示 `rwxr-x--x`
- `chmod u+x test`：给用户增加执行权限
- `chmod +x test`：给所有用户和组增加执行权限

- `chown root hello.txt`：将hello.txt所属用户修改为root
- `chown :root hello.txt`：将 hello.txt 所属用户组修改为root组

### 压缩&解压

市面上有非常多的压缩格式：

- zip：Linux、Windows、MacOS 常用
- 7zip：Windows常用
- rar：Windows常用
- tar：Linux、MacOS常用
- gzip：Linux、MacOS常用

Linux和Mac系统常用有2种压缩格式，后缀名分别是：

- .tar：称之为 tarball，归档文件，即简单的将文件组装到一个 .tar 的文件内，并没有太多文件体积的减少，仅仅是简单的封装

- .gz：也常见为.tar.gz，gzip 格式压缩文件，即使用gzip压缩算法将文件压缩到一个文件内，可以极大的减少压缩后的体积

| .tar \| .gz \| .tar.gz 格式命令               | 说明                                                             |
| --------------------------------------------- | ---------------------------------------------------------------- | --- | --- | ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tar [-c                                      | -x                                                               | -z  | -v  | -f] 压缩文件名 要压缩的目录或文件...` | 压缩或解压 `.tar` 或 `.tar.gz` 格式<br /> -c：创建压缩文件，用于压缩模式 <br />-v：显示压缩、解压过程，用于查看进度 <br />-x：解压模式 <br />-f：要创建的文件，或要解压的文件，-f 选项必须在所有选项中位置处于最后一个 <br />-z：gzip模式，不使用-z就是普通的 tarball 模式 |
| `tar -cvf dest.tar source1 source2... `       | 压缩到 `dest.tar`                                                |
| `tar -zcvf dest.tar.gz source1 source2...`    | 以gzip模式压缩到 `dest.tar.gz`                                   |

| `gzip file`                                   | 以gzip模式压缩单个文件                                           |
| `gunzip file.gz`                              | 只解压 `gzip` 压缩的 `.gz` 文件                                  |

::: warning

- -f 选项：必须在选项组合体的最后一位
- -z：建议在开头位置
- -C：单独使用，和解压所需的其他参数分开

:::

- %MEM：进程占用内存率

### 16. 端口

是设备与外界通讯交流的出入口。端口可以分为：物理端口和虚拟端口两类。

- 物理端口：又可以称之为接口，是可见的端口，如 USB 接口、RJ45 网口、HDMI 端口等
- 虚拟端口：是指计算机内部的端口，是不可见的，是用来操作系统和外部进行交互使用的

计算机程序之间的通讯，通过IP只能锁定计算机，但是无法锁定具体的程序。

通过端口可以锁定计算机上具体的程序，确保程序之间进行沟通。

**IP地址相当于小区地址，在小区内可以有许多住户（程序），而门牌号（端口）就是各个住户（程序）的联系地址。**

Linux系统是一个超大号小区，可以支持65535个端口，分为3类进行使用：

- 公认端口：1-1023，通常用于一些系统内置或知名程序的预留使用，如 SSH 服务的22端口，HTTPS 服务的443端口，非特殊需要，不要占用这个范围的端口
- 注册端口：1024-49151，通常可以随意使用，用于松散的绑定一些程序/服务
- 动态端口：49152-65535，通常不会固定绑定程序，而是当程序对外进行网络链接时，用于临时使用

### 22. 环境变量

环境变量是操作系统在运行的时候，记录的一些关键性信息，用于辅助系统运行。

在Linux系统中执行：`env` 命令即可查看当前系统中记录的环境变量。

环境变量是一种 `KeyValue` 型结构，即名称和值。

<br />

#### PATH

记录了系统执行任何命令的搜索路径（以:隔开）

<br />

#### $

在Linux系统中，$ 符号被用于取“变量”的值。

环境变量记录的信息，除了给操作系统自己使用外，如果我们想要取用，也可以使用。

取得环境变量的值就可以通过语法：`$环境变量名` 来取得

如：`echo $PATH` 、`echo ${PATH}ABC`

<br />

#### 自行设置环境变量

分为：

- 临时设置
  - 语法：`export 变量名=变量值`
- 永久生效
  - 针对当前用户生效，配置在当前用户的 `~/.bashrc` 文件中
  - 针对所有用户生效，配置在系统的 `/etc/profile` 文件中
  - 并通过语法 `source 配置文件` ，进行立刻生效，或重新登录 `FinalShell` 生效

<br />

#### 自定义环境变量PATH

`export PATH=$PATH:/home/xxx`
